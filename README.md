# domik-v-derevne

PWA для управления бронированиями загородного дома «Домик в деревне».

Дом 4 500 ₽/сутки за двоих (+500 ₽ за каждого доп. гостя, максимум 4).
Баня 3 500 ₽/2 ч за двоих (+500 ₽ доп. гость). Купель фурако (горячая) 4 500 ₽/сеанс.

- Бронирование на несколько дней через календарь.
- Часы заезда («первый день») и выезда («последний день»); занятые и часы уборки показаны тёмным сектором.
- Тёмная тема по умолчанию, переключение на светлую.
- Данные хранятся в Firebase Firestore (коллекция `bookings`).
- Вход для работника: 🔐, пароль по умолчанию `1234`.
- Черновик формы сохраняется автоматически в localStorage.
